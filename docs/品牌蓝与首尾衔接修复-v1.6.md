## 最新要求及参数

用户要求消除首尾白条、绿色改蓝色、浅底保留可见紫色，并指定品牌蓝 `#3B78DD`。随后要求 Light 呈现减弱：保留派生色值，通过降低光效幅度控制强度。

以下是合成前的 sRGB 色值；实际截图还受透明度、背景和混合影响，并非整段线条应直接等于 HEX。

| 项目 | 当前候选 |
| --- | --- |
| 品牌蓝基准 | #3B78DD，HSV H=217.4074°、S=0.7330、V=0.8667 |
| Light 蓝头 | #236EEB，H 同品牌、S=0.85、V=0.92 |
| Dark 蓝头 | #619DFF，同品牌色相，保留原深色端点 S=0.6189、V=1 |
| Light 紫尾 | #7C00D5；Dark 紫尾仍为 #992CE7 |
| Light 线条幅度 | 乘 0.75，比本轮较强候选减弱 25% |
| Light 柔光映射增益 | 从 1.9 降为 1.33，比本轮较强候选减弱 30% |
| Light 紫色过渡 | 过渡终点从尾程 0.9 提前至 0.55，尾迹衰减指数 2.0 → 1.35 |

Dark 的强度、过渡与衰减不随 Light 弱化。HSV 调整在 sRGB 空间进行，配置文件继续保存线性 RGB。窗口运动/缩放冻结高光和关联映射相位、保持显示的规则不变。

## 原因与修正

v1.5 处理了最亮中段的透明合成增亮，但只取中段剖面，漏掉了两端。渐隐线条比柔光作用范围窄，基础白色细边在柔光下露出，仍能形成间隔白条。此次在同一轮廓增加与流光绑定的连续接触覆盖，并修正局部预乘覆盖。用户在中间候选的实际测试中发现灰色首端：原因是新增中性接触阴影比彩色核心延伸更远。最终候选移除这段中性乘暗覆盖，改用同一适配蓝/紫色的接触着色，覆盖沿柔光作用范围连续渐隐；关闭流光时一起退出。基础 GlassStyle、基础 Light 阴影和描边参数未修改。

此前紫色在尾程较后才充分出现，而尾迹强度已经衰减得很低。此次只在 Light 提前蓝紫过渡并延缓尾迹消退，避免通过无限增强整体光效让紫色勉强可见。

这是实现及验证覆盖不足；文档中已有首端渐隐和柔光约束，却没有落实到首尾图像检查。现已补入首尾剖面和紫色可见性检查，v1.5 的视觉结论重开，保留历史证据。

## 性能与边界

修改发生在已有片元计算内，没有新增纹理、屏幕采集、统计 buffer、渲染 pass 或动画时钟。局部覆盖增加标量计算，不能称为零开销。本轮不重复 RSS 长测；没有用短测代替颜色、真实窗口和基线检查。原 U02-06 内存偏差仍按已知问题延期。
