# 统一流光几何与渐隐修复 v1.7

2026-09-14。状态：**SOURCE_IMPLEMENTED / LOCAL_RENDER_CHECKS_PASSED / USER_VISUAL_REVIEW_PENDING**。

## 最新约束

以用户最后明确的 Dark 效果为共同基准：Light 与 Dark 的长度、色段比例、首尾包络、线宽、时序一致，只在浅底颜色、透明度与合成细节上适配。不执行本轮中途拟议的独立紫段位置调整。

- 周期 7 秒、尾长占周长 0.20、同一方向和相位。
- 共用尾迹衰减指数 2.0、头部 smoothstep 渐隐、蓝紫过渡 `smoothstep(0,0.9,t)`。撤销 Light 的 1.35 衰减指数和提前到 0.55 的紫色过渡。
- 共用 `max(aa*0.75,0.3)` 高斯线宽尺度。本机 2x 为 0.375 pt，Light 从此前 0.75 pt 缩小 50%；不是把窗口或基础描边缩小。
- Light 品牌蓝派生色由 S=0.85 提至 S=0.95，V=0.92 不变，合成前 sRGB 约为 #0C60EB；色相仍来自 #3B78DD。紫色本身 S 已为 1，不虚称再次增加。
- 保留用户要求的浅底弱化透明度：线条幅度 0.75、映射增益 1.33；不再通过延长色段或增加接触色带补偿浅底可见度。最终颜色对比受背景与透明合成影响，并非 RGB 参数等于实际像素。

## 根因与实现

v1.6 的接触着色使用额外扩大、快速饱和的沿边包络，且只着色轮廓内侧；主线已经渐隐时，内侧仍留下颜色。它同时导致线条变粗和上下两侧渐隐范围不一致。将中性接触阴影换成蓝色仅修复灰头，未解决这个结构问题。

另一个原因是半透明基础边缘按原路径编码后，RGB 可能高于 alpha。若先混入微弱流光再由透明合成裁切，部分上侧像素仍被裁成白色，下侧已出现颜色，形成空白间隔。

本次移除接触包络、接触着色和相应参数，恢复同一细线轮廓。在 Light 流光合成前，把基础预乘 sRGB 限定在 alpha 范围内，再混入颜色。整条线的横截面共用相同首尾包络；内侧映射保留与 Dark 相同的柔光扩散模型。基础材质关闭流光时的路径和输出不变。

“完整渐变”落实为细线横截面一起渐隐，不新增 Light 专用线性时间曲线；曲线以最后确认的 Dark 为准。没有移动阴影、另建内缩描边或扩大窗口。
