# 本机版本已知问题

## U02-06 — 最大尺寸 RSS 一次性抬升

状态：**用户接受为本机版本已知问题，延期排查**（2026-09-13）。当前构建拖动及最终视觉验收已完成，本机版本已以“带已知问题验收”闭合，见 [验收报告](缩放CPU修复与最终验收-UP02.md)。

适用构建：9mXYWr；Apple M4 / macOS 26.5.2 / 内置 2x 屏。发生场景为实际最大主体 2904×1408 px，默认主体仍为 800×100 px。

实际现象：第 165 秒 RSS 约 82.56→91.66 MiB，一次增加约 9.09 MiB，随后基本持平。正式 5 分钟斜率 2.72570466 MiB/min、首末分钟差 9.171875 MiB，原门槛 ≤1 / ≤5 因此仍为失败。原始记录：[核心结果](evidence/WP-06-performance-20260913T122902Z/result.json)、[时间关联](evidence/UP-02-final-review-R5/rss-comparison.json)。

推断：首次完整像素相同比较与跳升同时发生，可能涉及首次读取缓冲导致页面驻留；具体 VM 归属未证实，不能称为已经修复，也没有证据据此认定持续泄漏。

接受范围仅为这项已记录的最大尺寸 RSS 偏差。原 CPU、GPU、帧率、延迟、默认内存、隐藏回收及视觉要求不变；原失败数据不修改为 PASS。其他系统与显示环境仍未验证。数值验收与产品决定分别记录为“原门槛未通过”和“用户接受已知问题”。

后续：[UP-03 排查方案](最大尺寸RSS复核与后续修复方案-UP03-v1.0.md) 延期，未启动；本次不再为这一偏差继续修改产品代码。
