## 已实现

- 未授予录屏权限、采样启动失败或 Metal 初始化失败时，显示 NSVisualEffectView 系统材质；保留玻璃主体、圆角、透明外边距、拖动与右键“关闭”。没有内部错误面板或业务内容。
- blank/suspended/stopped 帧会清除旧样本并隐藏旧自定义材质；流失败显示降级。仅在有效新帧完成后切回自定义玻璃。黑色像素本身不会被误判为受保护内容。
- 捕获失败不作高频重试；可见性/环境事件或明确的恢复意图重启。降级材质由系统合成，零自定义 GPU 提交不代表系统 GPU 完全无工作。
- 显示器、backing 或显示器几何不一致时，以降级框体交接并串行停止、重建捕获；目标显示器在采样准备前检查，避免扩大旧屏采样。动画中断保留最后已提交的实际像素数，不用新 scale 乘旧 pt 尺寸。
- 成功采样时的 Metal shader 和 GlassStyle 未在本包改动。系统降级材质保持可用外形，不承诺与自定义 shader 的颜色及内发光完全相同。
