# material 描边加宽与浅色对比 v1.7

2026-09-15。状态：PREVIEW_COMPLETE / DEFAULT_UNCHANGED / VISUAL_SELECTION_PENDING。

用户授权尝试 B 加宽、复用旧版边缘过渡，并补充浅色描边不明显的问题。本轮只新增 `scripts/preview_rim_widths.py`，复用原生预览夹具；没有修改产品默认描边、打包、推送或运行 RSS 测试。

## 小样定义

| 标识 | 参数 | 目的 |
| --- | --- | --- |
| 当前 | 0.55 pt / 白色 alpha 0.40 | 当前默认对照 |
| B1 | 0.70 pt / 线芯 alpha 0.36 / 柔光峰值 0.08 | 小幅加宽，控制厚重感 |
| B2 | 0.85 pt / 其余与 B1 相同 | 判断进一步加宽的收益与代价 |
| L1 / L2 | 0.55 / 0.70 pt / alpha 0.40 | 复用旧版外轮廓与内侧描边 smoothstep 覆盖函数 |
| W（浅色） | B1 宽度与柔光，白色 alpha 提至 0.65 | 单独提高白边强度 |
| S（浅色） | W，加峰值 alpha 0.08、向内指数衰减的暗衬 | 提供邻近明暗对比，保留白色线芯 |
| LS（浅色） | L2，白色 alpha 0.65，加同样暗衬 | 比较另一覆盖函数与暗衬组合 |

本组 B 柔光 sigma=0.80 物理像素、峰值 0.08；相对 v1.6 的峰值 0.12 有意减弱，以免加宽后过重。暗衬衰减长度 1.8 物理像素，贴着边缘单调衰减，没有间隔，也不是新增一条固定内描边。

L 只复用旧代码的覆盖函数，仍在系统玻璃上叠加白边；没有恢复背景采样、像素亮度自适应、旧版内光与阴影的联合合成。因此它不是屏幕采样版的完整复刻，也不能用其结果否定旧版整体效果。

## 原尺寸评审

- 深色：B1 更清楚，B2 更连续但明显更厚；加宽没有保证所有圆角明暗变化消失。B1 是更克制的继续调校候选，B2 保留供比较。
- 浅色：只加宽或增强白色，收益仍有限。S 的边界较容易辨认，但带来一定灰边感；是否符合期望仍需用户判断，不能直接宣布浅色问题解决。
- 单独复用旧版覆盖函数，本轮没有观察到明确优势，不把迁移公式本身当成修复完成。
