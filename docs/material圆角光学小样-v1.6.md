# material 圆角光学小样 v1.6

2026-09-15。状态：PREVIEW_COMPLETE / NOT_PROMOTED。

用户授权尝试局部亮度补偿、极窄柔光及组合方案。本轮仅新增预览夹具和脚本；`StaticGlassRim` 产品默认代码未修改，也未打包或推送。v1.5 的视觉未通过状态保持。

## 参数与真实截图

使用实际产品 FramePanel 和 Clear Glass，通过临时编译的描边变体生成屏幕合成截图。框体为 800×100 px，本机 macOS 26、2x；流光关闭以观察基础白边。拼图保持原尺寸，局部图为 4 倍最近邻放大，未调色或使用图像生成模型。

| 小样 | 处理 | 实际代价 |
| --- | --- | --- |
| 0 当前版 | 0.55 pt，白色 alpha 0.40 | 参照 |
| A 局部补亮 | 圆弧/直线接点附近最高增益 1.30，沿接点距离以 sigma=5 px 衰减 | 有意改变局部亮度，不是保持原亮度的算法修复 |
| B 极窄柔光 | 线芯乘 0.90，叠加峰值 alpha=0.12、sigma=0.85 px 的内侧柔光 | 视觉略柔、略厚，亮度分布也改变 |
| C 组合 | A 与 B 同时开启 | 局部补亮更明显，需检查亮斑 |

首轮发现旧小图的拉伸中心仍处于补亮范围，会把局部增益拉长到整条直边。已扩大角部固定区域，使补亮经过至少约 3 个 sigma 衰减后才进入拉伸区；保留的截图均来自修正后的小样。当前 2x 下模板为 98×98 px，单张 RGBA8 原始数据约 37.5 KiB；该数值不是实测 RSS 增量。

## 评审结论

原尺寸下三种方案都没有表现出足以确认问题解决的显著改善。B 的过渡相对自然，但以更柔、更厚的观感为代价；A 和 C 的补亮存在局部亮点倾向。浅色下各组差别更小。上述是本轮图片评审判断，尚无用户视觉选择，不把候选完成等同于修复通过。

因此不替换产品默认参数，不宣布问题闭合。可将 B 保留为进一步视觉调校的方向，不能直接将其作为已接受版本。

## 复核与范围

```sh
python3 scripts/preview_rim_optics.py
```

脚本从产品描边源码生成临时变体，并直接复用 FramePanel；不会覆写生产文件。需已有 release 构建、背景夹具和桌面访问权限。8 组原生预览拍摄完成后自动退出。只有源码模板匹配时才注入实验公式，避免静默使用失效变体。

本轮没有重复 RSS 测试，也没有做流光、运动或其他屏幕环境的回归；如后续选择某个候选接入产品，再验证对应集成行为。当前只交付静态效果比较。
