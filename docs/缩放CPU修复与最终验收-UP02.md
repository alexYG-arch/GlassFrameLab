## 已接受的内存偏差 U02-06

最大主体为 2904×1408 px。原测量第 165 秒 RSS 约 82.56→91.66 MiB，一次增加约 9.09 MiB，随后基本持平。5 分钟斜率 2.72570466 MiB/min、首末分钟差 9.171875 MiB，仍超过原 ≤1 / ≤5 门槛。

首次完整像素相等比较与跳升同时发生，支持缓冲首次 CPU 读取引起页面驻留的假设；具体 VM 归属没有证实。原失败数据完整保留，不称为已修复，也不能据此确认持续泄漏。用户接受它为当前本机版本已知问题、延期排查，详见 [已知问题](本机已知问题.md)。[UP-03](最大尺寸RSS复核与后续修复方案-UP03-v1.0.md) 为 DEFERRED，未启动。
