# 浅底流光增纯修复 v1.8

2026-09-14。状态：**SOURCE_IMPLEMENTED / LOCAL_RENDER_CHECKS_PASSED / USER_VISUAL_REJECTED / REFERENCE_RESEARCH_PENDING**。

后续用户反馈本版 Light 仍不理想，转入 Microsoft 效果参考研究；数值检查通过不代表视觉验收通过。

用户认为 v1.7 的 Light 仍发灰显脏，要求继续提高饱和度。本次继承 Light/Dark 共用长度、色段比例、线宽、渐隐和时序的约束。

## 调整

合成前的高饱和颜色叠加到低透明度白底后，实际像素仍会变淡。仅把输入 S=0.95 改到 1，对紫色等已满饱和色没有进一步作用，不能把色值数字上升当作实际效果改善。

- Light 输入饱和度提高至上限，蓝色 S=1、V=0.92、H 保持品牌色 #3B78DD 的 217.4074°，合成前色约 #0058EB。
- 在已有 Light 合成函数中，将流光颜色相对其最高通道的色差乘 1.30，再把最终预乘结果限制到有效范围。这只增强流光带来的颜色分量，不对捕获背景或整个玻璃做饱和度调整，也不改 alpha。
- 去掉 Light 流光附加的中性压暗；基础玻璃内阴影和外阴影保持原样。Dark 仍使用原合成路径。
- 保留弱化后的线条幅度与映射强度；没有加宽线条、加长紫色尾迹、延长头部或新增接触着色。

该方法在中性背景上保持流光色相并提高合成色差。彩色背景及色域裁切会影响最终感知，不能承诺所有背景下等量增饱和。

## 验证

最终源码 Release 编译、生产 Metal shader 固定输入回归通过。基础 Light 的四类输入仍与冻结基线一致；关闭基础自适应后六类输入输出不变。首尾上下截面颜色覆盖、线宽、脱离线头的残留色带等回归通过。

与 v1.7 相同输入、相同相位对照：

- 白底、浅灰底各四个主体/尾部/映射采样点的合成饱和度提高约 35%～37%；这是八个固定采样点的结果，不是全图平均或所有背景保证。
- 白、灰、深底、暗色细节各六个流光相位的 alpha 通道像素差为 0。
- Dark 及暗色细节各六个相位的完整 RGBA 像素差为 0。
