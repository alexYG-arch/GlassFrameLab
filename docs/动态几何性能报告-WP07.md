# WP-07 动态几何性能报告

状态：当前构建预算检查通过，独立工作包结论见 [WP-07](workpacks/WP-07.md)。本报告不代替 WP-08 环境兼容或 WP-09 最终验收。

## 构建与口径

固定应用构建 `1XCWlX`，默认主体 800×100 显示像素，2x 下为 400×50 pt；含外扩散留白的最终 drawable 为 824×124 px。实际最大主体 2904×1408 px，panel/drawable 为 2928×1432 px。

基准为 Apple M4 / 24 GB / macOS 26.5.2，内置屏 1512×982 pt、3024×1964 backing px、2x，接通电源，低电量模式关闭。每个正式场景预热 30 秒、采样 300 秒，CPU/RSS 每秒一次，P95 使用 nearest-rank。无窗口基线与静态场景并行，其他视觉场景串行执行。

呈现 FPS、帧间隔和延迟只使用正值 `MTLDrawable.presentedTime`；静态/恢复首帧可有零时间戳，其实际可见性由原生截图另行验证，不为统计补绘。GPU 时间与端到端延迟分开计算。连续移动通过测试入口调用产品几何控制器，不冒充鼠标事件注入。

证据：[汇总](evidence/WP-07-verification-20260911T102715Z/budget-consolidated.json)、[串行运行](evidence/WP-07-verification-20260911T102715Z/result.json)、[冻结预算](workpacks/WP-00-performance-budget.md)。`WP-06-` 目录前缀来自复用脚本，以下均为本次 `1XCWlX` 构建。

## 隐藏、恢复和静态缓存

默认及最大尺寸各 20 次恢复均保存原生窗口截图并检查主体可见；实际恢复截图已复核，圆角平滑、背景连续。默认 20 次后隐藏 RSS 增量 0.375 MiB，最大尺寸 -15.516 MiB，均低于 10 MiB 上限。隐藏后停止捕获和 GPU 提交，最新缓冲与 GPU 在途工作为 0。

默认隐藏 CPU 中位数 0.299%，相比无窗口基线增加 0.273 个百分点，低于 0.5 个百分点预算。

[样式缓存](evidence/WP-06-style-updates-20260911T102731Z/result.json) 三次参数切换共四次 GPU 合成、一次模糊、一次中间纹理分配；提交数不是呈现数。旧脚本日志的 four presentations 表述已纠正，原始日志不改写。

## 修复历史与结论边界

原圆角毛边来自实际 drawable 停留在 412×62 px，被拉伸到更大框体；已修正为实际显示像素并检查底层纹理尺寸。后续 6LthON 缩放长测出现帧间隔 P95 66.6665 ms、609 个零时间戳的失败，保留在 [原结果](evidence/WP-07-resize-20260911T101338Z/result.json)。

当前修复在 GPU 完成、目标几何有效后，先排队 drawable，再提交和 flush 对应窗口几何事务；保持默认异步 Metal 呈现，不宣称两个系统接口有原子保证。当前缩放长测为 29 FPS、P95 41.666584 ms，仍保留 71 个零时间戳，不把零值改为已呈现。该数据支持本次顺序修复有效；视觉另据实际截图判断。

CPU、GPU 时间和工作次数为功耗代理，未测量瓦数。正式效果开关 A/B 与最终视觉在 WP-09；macOS 13、外接屏、非 2x、真实锁屏/全屏/Space 等环境边界由 WP-08 分别验收，不以本机通过替代。
