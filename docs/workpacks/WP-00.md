默认运行普通窗口，手动退出；`--duration` 单位秒，仅接受有限正数；`--baseline` 不创建窗口；`--animate` 仅启用校准动画。输出目录必须为新运行目录。默认不启动任何录屏权限流程。

视觉验收仅为校准窗口可见且固定图案完整；不是玻璃样式验收。性能验收仅针对工具和基线；真实玻璃帧率、GPU 时间、能耗尚未测量。具体后续预算按主规约 §4.3.1 提出并确认，未确认不得关闭本包。

修改范围：上述实现、脚本、README、测试与 docs/evidence。范围外：WP-01～09、内部内容、采样与 Metal、发布或 Git 提交。
