## 静态与回收

受控静态完整测量期间没有新增模糊或合成，包含启动阶段累计各一次；局部中间纹理只有一张、分配一次，queueDepth=3，最多一个 command 在途。样式三次切换累计四次合成，仍只模糊一次，不自激持续升频。

默认 20 次显示/隐藏后 RSS 比首次预热隐藏基线低 4.09375 MiB，隐藏 CPU 中位 0.29085%；最大尺寸同样 20 次恢复都呈现新帧，最终 RSS 比其基线低 9.765625 MiB。最终无保留采样帧或 GPU 在途工作，隐藏后无周期性采集/提交。

前两次静态记录有短暂的新像素输入，用户确认期间切换到 Finder；原始 FINDINGS 记录保留。后续保持背景固定、使用相同应用和夹具的完整静态测量通过。没有修改产品代码或宽松处理静态阈值来消除失败。

## 新增成本与限制

外侧每边 6 pt 留白将默认 drawable 从 800×100 增至 824×124 px，面积增加 27.72%；单张 BGRA8 纯像素数据约由 0.305 增至 0.390 MiB，实际分配需考虑系统对齐和多 drawable。局部捕获仍为 472×122 px；最大尺寸为 1512×776 px。新增模糊 pass=0，新增中间纹理=0，静态持续新增提交=0。

同构建、同窗口范围的关闭光效参考组：CPU 5.5096%、RSS 66.203125 MiB、GPU P95 3.03429 ms。完整效果减关闭状态的观察差值为 CPU +0.3236 个百分点、RSS −5.390625 MiB、GPU P95 −0.28054 ms。这些负差值不能证明光效节省资源：两次运行有环境波动，零强度开关也不保证驱动删除所有对应算术。它是开关状态下整条管线的实测对照，不是纯新增指令成本。

关闭参考组还出现 max 416.16675 ms 延迟、4 个未呈现 drawable 和 50.000041 ms 的帧间隔 P95，因此没有将其验收为另一个稳定质量档。完整默认预设没有这些超限。旧 WP-05 默认动态为 CPU 4.20055%、GPU P95 0.08046 ms、29 FPS；升级值为 5.8332%、2.75375 ms、27 FPS。旧新运行时间和管线不同，这一总体变化不能只归因于光晕面积或 shader，也不能用旧成绩替代升级证据。

时间戳在 CSV 中保存纳秒精度。分析器先用十进制定点相减，再计算毫秒，避免大 uptime 浮点抵消将精确 50 ms 写成略大于 50；门槛没有添加容差或放宽。

CPU/GPU 时间与提交计数只是功耗代理。本报告支持性能预算和节能调度结论，不提供整机瓦数、电池续航或全部系统兼容结论。后续 WP-07 改动和 WP-08 环境验证仍需对应证据。
